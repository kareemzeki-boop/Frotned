## 2025-03-24 - Request for Quotation (RFQ) Modal Micro-UX
**Learning:** This static HTML project lacks a reactive framework, requiring manual state management for dynamic UI elements like character counters. Accessibility standards (labels, aria attributes) must be manually enforced on form components.
**Action:** Always pair labels with inputs using 'for/id' and initialize dynamic UI state within 'open/toggle' functions to ensure consistency across multiple modal activations.
